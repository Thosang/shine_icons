Installation

เพิ่ม CSS ของ SHINE SDG Icons ในหน้า HTML ของคุณ 

<link rel="stylesheet"


href="https://thosang.github.io/shine_icons/sdg-icons.css">

Usage with <div>

สามารถใช้ Icon ด้วย class sdg-icon และ class ของ SDG

HTML

<div class="sdg-icon sdg-01"></div>

Result

Usage with <i>

สามารถใช้ Icon กับ <i> ได้เช่นเดียวกัน

HTML

<i class="sdg-icon sdg-01"></i>

Result
