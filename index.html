Installation

เพิ่ม CSS ของ SHINE SDG Icons ในหน้า HTML ของคุณ 

<link rel="stylesheet"
href="https://thosang.github.io/shine_icons/sdg-icons.css">

Usage with <div>

สามารถใช้ Icon ด้วย class sdg-icon และ class ของ SDG

HTML

<div class="sdg-icon sdg-01"></div>

Result

Usage with <i>

สามารถใช้ Icon กับ <i> ได้เช่นเดียวกัน

HTML

<i class="sdg-icon sdg-01"></i>

Result

Multiple Icons

<i class="sdg-icon sdg-01"></i>
<i class="sdg-icon sdg-02"></i>
<i class="sdg-icon sdg-03"></i>

วิธีการใช้งาน: กำหนดขนาดไอคอน

ไอคอนทุกตัวมีขนาดเริ่มต้นที่ 150px x 150px แต่คุณสามารถปรับขนาดได้ 2 วิธี คือใช้ class สำเร็จรูป หรือ กำหนดขนาดเอง ด้วย CSS

วิธีที่ 1: ใช้ class ขนาดสำเร็จรูป

เพิ่ม class ขนาดต่อท้าย sdg-icon ได้ทันที ไม่ต้องเขียน CSS เพิ่มเอง 

<i class="sdg-icon sdg-01 sdg-sm"></i>
<i class="sdg-icon sdg-01 sdg-md"></i>
<i class="sdg-icon sdg-01 sdg-lg"></i>
<i class="sdg-icon sdg-01 sdg-xl"></i>

ผลลัพธ์

32px

sdg-md
64px

sdg-lg
128px

sdg-xl

วิธีที่ 2: กำหนดขนาดเอง (Custom Size)

ถ้าต้องการขนาดที่ไม่ตรงกับ class สำเร็จรูป สามารถกำหนดขนาดเองผ่าน style หรือเขียน CSS class ของตัวเองได้ 

<i class="sdg-icon sdg-01" style="width:100px;height:100px;"></i>

ผลลัพธ์

40px

100px

180px

ตัวอย่างการใช้งานจริง: การ์ดแสดงเป้าหมาย SDG

ผสม class ขนาดเข้ากับข้อความ เพื่อสร้างการ์ดแสดงรายการเป้าหมาย 

<div class="icon-card">
  <i class="sdg-icon sdg-02 sdg-lg"></i>
  <h3>SDG 2: Zero Hunger</h3>
</div>
